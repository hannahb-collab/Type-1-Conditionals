Grammar Basics

What are Type 1 Conditionals?

We use Type 1 Conditionals (First Conditional) to talk about real or possible future situations using will or modal verbs like can, may, might, should!

1

The Golden Formula

If + Present Simple + will + base verb

If it rains tomorrow, we will stay indoors.

2

Flipping the Order!

Put the result clause first! No comma is needed between clauses.

We will stay indoors if it rains tomorrow.
3

Using Modal Verbs ✨

Instead of will, use can, may, might, or should for ability, permission, or possibility!

Ability (能力): "If you finish early, you can go play."
Possibility (可能性): "If it snows, we might build a snowman."
Advice (建議): "If you feel sick, you should rest."
